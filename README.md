# AutoAgenda

## Sobre

Projeto Integrador do Centro Universitário Senac, feito com HTML5, CSS e JavaScript puro, com os dados salvos no LocalStorage do navegador.

## Tema 
Cadastro de clientes, veículos, serviços e ordens de serviço para pequenas oficinas mecânicas.

## Como abrir

Não precisa instalar nada: abra o arquivo `index.html` no navegador.

## Para o grupo

- Modelo de página pronta para copiar: `clientes.html` + `js/clientes.js`
